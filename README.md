# Multi-Panel RAG AI Agents Academic Assistant Platform

A next-generation, high-performance web platform designed to unify university-level academic workflows. Driven by custom sessional RAG AI evaluation agents, it provides tailor-made workspaces for students, teachers, and researchers.

## 🚀 Key Architectural Panels

### 🎓 Student Workspace
- **Smart Study Companion**: Upload text-books, slide decks, or lecture notes.
- **Auto-Summarization**: Hinglish & English summary generators with multi-tier density control.
- **Sessional Deliverables**: Instantly generate evaluation flashcards and practice quizzes.
- **Smart Citation Assistant**: Extract IEEE, APA, or MLA metadata from text snippets.

### 👩‍🏫 Teacher Workspace
- **Advanced Evaluator**: Input target curriculum and syllabus schemas.
- **Automated Question-Paper Architect**: Generate rigorous question papers matching custom difficulty distributions (Easy, Medium, Hard).
- **Evaluation Pipelines**: Cross-examine submitted answer keys using sessional verification agents.

### 🔬 Researcher Workspace
- **Cognitive Graph Architect**: Ingest academic PDFs to extract a persistent knowledge graph.
- **Active Citation Grapher**: Trace semantic cross-references between loaded papers.
- **Paper Summarizers**: Distill dense methodology and mathematical formulation blocks instantly.

---

## 🛠️ Core Technology Stack
- **Framework**: React 18 & TypeScript (Vite dev engine)
- **Styling & UI**: Tailwind CSS + Shadcn Primitives
- **Animations**: Framer Motion & CSS Variables
- **State & Data**: React Router Dom v6 + Lucide Icons

## 💻 Local Development Setup

To launch the dev server locally:

```sh
# 1. Clone or download the workspace
git clone <YOUR_GIT_URL>

# 2. Go to the project directory
cd Multi-Panel-RAG-AI-Agents-Academic-Assistant-Platform

# 3. Install core dependencies
npm install

# 4. Start the interactive development server
npm run dev
```
